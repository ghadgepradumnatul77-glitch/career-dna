# Contributing to Career DNA

Thank you for your interest in contributing to Career DNA!

## Code of Conduct
Please maintain a respectful, welcoming environment for all contributors.

## How to Contribute

1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Clone & Branch**:
   ```bash
   git clone https://github.com/ghadgepradumnatul77-glitch/career-dna.git
   cd career-dna
   git checkout -b feature/your-feature-name
   ```
3. **Set Up Local Environment**: Follow the setup instructions in [README.md](README.md).
4. **Make Changes**: Ensure all changes follow project architecture, Python PEP-8 coding style, and React component patterns.
5. **Run Tests**:
   - Backend: `python -m unittest discover -s Backend/tests`
   - Frontend: `npm run build`
6. **Commit & Push**:
   ```bash
   git commit -m "Add new feature: description"
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request**: Submit your PR with a clear summary of changes.

Thank you for helping build Career DNA!
