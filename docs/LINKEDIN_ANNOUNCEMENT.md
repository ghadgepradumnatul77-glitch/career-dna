# 🌐 LinkedIn Launch Announcement

🚀 **Proud to launch Career DNA — AI Career Intelligence & Skill Gap Platform!** 🧬

Resume keyword parsers are broken. Candidates struggle with generic feedback while engineering leads struggle to verify candidate skills against real production requirements.

To solve this gap, I built and deployed **Career DNA**: an end-to-end full-stack AI platform that analyzes resume text, syncs GitHub repository activity, and computes a verified **Career DNA Score** and skill matrix.

### 💡 Key Platform Capabilities:
- **Resume & GitHub Skill Ingestion**: NLP parsing of text resumes combined with GitHub repository language metrics.
- **Career DNA Readiness Engine**: Computes overall score (e.g. 88/100), primary archetype (*Backend / AI Architect*), and verified skill levels.
- **Target Role Skill Gap Analyzer**: Compares engineer profiles against target roles (*AI Engineer*, *Senior Backend Lead*) to compute match percentages and missing competencies.
- **Actionable AI Recommendations**: Generates personalized learning goals with real-time completion tracking.
- **Production Architecture**: Deployed with Vercel (React 18 + Vite), Render (FastAPI + Uvicorn), and Supabase (Managed PostgreSQL 17).

🛠 **Tech Stack**: Python | FastAPI | PostgreSQL | SQLAlchemy | Alembic | React 18 | Vite | Bootstrap 5 | JWT | Axios
