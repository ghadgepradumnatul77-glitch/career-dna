## 🌐 2. LinkedIn Project Post

🚀 **Excited to share my latest project: Career DNA — An AI-Powered Career Intelligence & Skill Gap Platform!** 🧬

Resume keyword matching is broken. Candidates guess keywords while engineering managers struggle to verify actual hands-on capability. 

To solve this, I built **Career DNA**, a full-stack platform that analyzes raw resume text, syncs GitHub repository activity, and generates a verified **Career DNA Score** and skill matrix.

### 💡 Key Highlights:
- **FastAPI & PostgreSQL Backend**: Secure JWT authentication, Alembic schema migrations, and RESTful architecture.
- **Multi-Source Data Ingestion**: Parses resume text and synchronizes GitHub profile activity.
- **Target Role Skill Gap Analyzer**: Benchmarks candidate profiles against target roles (e.g., *AI Engineer*, *Backend Architect*) to highlight match percentages and missing competencies.
- **Actionable AI Recommendations**: Generates step-by-step learning goals with real-time completion tracking.
- **Sleek React 18 UI**: Modern AI dark-mode dashboard built with glassmorphism, responsive grid components, and live metrics.

🛠 **Tech Stack**: Python | FastAPI | PostgreSQL | SQLAlchemy | Alembic | React 18 | Vite | Bootstrap 5 | JWT | Axios
